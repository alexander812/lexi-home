# Lexi Home

Лендинг приложения [Lexi](https://app.lexi.casa) — бесплатного тренажёра для запоминания слов и выражений.
Astro 7, тёмная тема, две локали: английская в корне (`/`) и русская в `/ru`.

```bash
npm install
npm run dev      # http://localhost:4321
npm run build    # dist/
```

Контекст для дальнейших задач — в [PROJECT.md](./PROJECT.md): структура, локализация, токены,
ассеты (скриншоты, видео, APK) и следующие шаги.
